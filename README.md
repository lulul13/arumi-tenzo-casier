# 🍃 Casier d'Arumi Tenzo · Section scientifique

Site en ligne : **https://lulul13.github.io/arumi-tenzo-casier/**

- `index.html` : le site
- `donnees/casier.json` : tous les documents (modifié automatiquement par le site en mode archiviste)
- `donnees/cle.json` : clé GitHub verrouillée par le mot de passe des archivistes (fabriquée avec `outil-mot-de-passe.html`)
- `images/` : images ajoutées depuis le site
- `r/` et `bilan/` : petites pages de partage (aperçu Discord), créées automatiquement à chaque publication par `outils/generer-pages.js`
- `.github/workflows/publier.yml` : publie le site sur GitHub Pages à chaque changement (réglage Pages → Source : GitHub Actions)
