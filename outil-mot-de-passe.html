🔑 Mot de passe des archivistes

Cette page fabrique le fichier cle.json. Il contient ta clé GitHub, verrouillée par le mot de passe que tu choisis. Tout se passe dans ton navigateur : rien n'est envoyé nulle part.

Au moins 12 caractères. Le plus sûr : 4 mots au hasard, par exemple fiole-rouge-herbe-lune-42.

✅ Le fichier cle.json vient d'être téléchargé. Envoie-le dans le dossier donnees du dépôt GitHub (voir le guide, étape 6).
